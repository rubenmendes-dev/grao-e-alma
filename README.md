# Grão & Alma

## Sobre o projeto

O **Grão & Alma** é um website fictício de uma cafetaria localizada no Porto, desenvolvido no âmbito de uma formação em programação Web.

O objetivo do projeto é criar uma página moderna, acolhedora e intuitiva, onde os visitantes possam conhecer a cafetaria, explorar o menu e descobrir as suas especialidades.

Este projeto encontra-se em desenvolvimento e permite aplicar e aperfeiçoar conhecimentos de HTML5, CSS3 e controlo de versões com Git.

## Funcionalidades

- Apresentação da cafetaria e da sua identidade visual.
- Menu com diferentes categorias de produtos.
- Apresentação de bedidas quentes e frias.
- Seleção de especialidades, refeições ligeiras e sobremesas.
- Imagens ilustrativas dos produtos.
- Navegação entre as secções do website.
- Organização visual com HTML e CSS.

## Tecnologias utilizadas

- **HTML5** - Estrutura e organização co conteúdo.
- **CSS3** - Estilização e apresentação visual do website.
- **Git** - Controlo de versões e histórico das alterações.
- **GitHub** - Alojamento e partilha do repositório do projeto.

## Como visualizar o projeto

1. Descarregar o repositório do GitHub ou cloná-lo através do Git.
2. Abrir a pasta do projeto no computador.
3. Abrir o ficheiro "index.html" num navegador Web.

Para visualizar corretamente o website, é necessário manter o ficheiro "style.css" e a pasta "imagens" na estrutura original do projeto.

## Estado do projeto

O Grão & Alma encontra-se em desenvolvimento. O website poderá receber novas secções, funcionalidades e melhorias visuais ao longo da formação.

## Nota

Este projeto foi desenvolvido exclusivamente para fins educativos. A cafetaria e as informações comerciais apresentadas são fictícias.
